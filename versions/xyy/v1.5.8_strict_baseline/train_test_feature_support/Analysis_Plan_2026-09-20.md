# 训练/测试县特征支持分析

用户已授权分析，日期2026-09-20。全部新增文件仅写入本目录；不画图、不训练、不重载模型、不修改旧文件、不生成预测。测试未来停电标签未提供。

## 问题与比较范围

1. 63个测试县相对239个训练县，哪些已知条件缺少相似参照？
2. 239个训练县原有的稀疏条件，在加入63个测试县后是否获得更近参照？
3. 区分地理邻近与特征邻近，并区分真实新增测试参照与解除原CV整折排除带来的变化。

## 固定输入和窗口

复用共同误差调研的18列主匹配：历史7列、天气7列、静态4列，三组等权。历史仅0–71；天气只使用赛事已经提供的整段；测试县未来P/N/D/R全部缺失。不使用未来训练结果、误差、severity、县/州编码作匹配变量。

保留h=1/6/24/48与原目标日交集，共21个h×日窗口。主匹配称context。解释性分解另算history_only、weather_only、static_only；source_cache_rank为此前来源输入摘要ECDF敏感性（h1/h24=183列、h6/h48=163列）。所有输出表明视图，不能混合不同视图的距离。

坐标只用于另算球面地理距离(km)，不加入特征距离。所有县同属一片区域不意味着其初始停电幅度、暴露、客户规模或联合条件相似。

输入核查发现测试Montour PA (42093)历史OSI全零，原缓存的hours_since_peak按设计为NaN；主18列无缺失。仅在source_cache_rank敏感性中，将这个“没有观测峰值”的状态编码为−1，有限值仍为训练ECDF的[0,1]，不把NaN伪装成最大峰值年龄。该人为编码可能影响敏感性距离，主结论使用无此字段的context。共有尾部天气列全部缺失时统一编码0、保留列数分母；不删除测试县、不改原缓存。

## 公平的参照比较

全训练参照：变换和标准化只拟合239训练县。训练基准是每县排除自身后的其他238县；测试县参照是全部239训练县。加入测试县后，训练县参照变为其余238训练县+63测试县。两次比较沿用同一个训练拟合变换与同一参考阈值，不能重新拟合到302县。

OOF对照：三套旧CV分别复现查询县整折排除的基准（约191–192参照县），再仅添加63测试县，仍排除原验证折其余县。标准化、ECDF和阈值均冻结在原训练折。该对照单独报告，不能与全训练结果混称。

测试县即使与训练离群县相似，也只提供无标签的输入支持，不等于增加已知未来结果的监督训练案例。最近距离随候选增加只能下降或不变，这本身不是模型收益。

## 新指标定义（每个视图、窗口和固定训练参照分别计算）

- d1：查询县到允许候选中最近一县的距离。d5：到第五近县的距离；检查是否只是孤立地找到一个近邻。
- reference_d1_q95 / reference_d5_q95：原训练参照县各自排除自己后的d1/d5的95%分位数(method=linear)。
- d1_percentile / d5_percentile：查询距离不小于多少比例的上述训练参考距离；0–100，仅为经验位置。
- flag_d1 / flag_d5：距离严格超过对应原训练q95（数值容差1e-12）。这是预先固定的诊断标记，不是校准的异常概率，也不是预测错误概率。
- 新增测试近邻：加入后排名前5中测试县数量；nearest_split显示最近邻属于train/test。
- relative_d1_reduction_pct：100×(原d1−加入后的d1)/原d1；原d1=0时定义为0并保证新d1=0。
- cleared_d1_flag：原来flag_d1为真、加入测试县后在同一固定阈值下为假。
- flagged_window_fraction：某县21个h×日窗口中被标记的比例；窗口重叠且历史重复，不是21次独立试验。另按h单独列出分子/分母。

主表列所有63测试县；简表按context被标记窗口数、最大d1/q95、FIPS排序列前10。预先规定“频繁”仅指>=一半窗口被标记，不称统计显著。训练县同法排序，并单列此前重点县。原尺度单列超范围、距离三组贡献和地理距离帮助解释；单列均在范围内也不代表联合条件被覆盖。
