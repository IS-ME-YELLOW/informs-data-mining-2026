# 表头与统计口径说明

本文的“离群/支持不足”均是已知特征空间的相对距离描述，不是已知测试RMSE高，不是异常数据判定，也不是预测失败概率。所有阈值只依据训练输入，未使用测试未来停电结果。

## 基础范围

| 字段/术语 | 明确定义 |
|---|---|
| county / fipsCode | 县名/五位行政识别码，只用于键、展示和自排除，不作为距离变量 |
| dataset | train=239有标签训练县；test=63仅已知截止前停电历史的测试县 |
| horizon / h | 预测horizon，用来确定对应输入和有效目标小时，不是一个持续时间标签 |
| target_day | 从2026-03-11开始的日序号，3=3月14日、8=3月19日 |
| 21个窗口 | h1有6日、h6有6日、h24有5日、h48有4日；每一天与该h有效目标范围取交集。窗口重叠，不能视为21次独立试验 |
| view=context | 历史7列、天气7列、静态4列；三组等权的标准化距离。历史和部分长尾变量先作固定变换 |
| history/weather/static_only | 仅使用对应一组，解释哪类信息缺参照，不直接等同于完整模型输入风险 |
| source_cache_rank | 对应来源输入的县日均值作训练ECDF变换并按组等权；h1/h24含邻县摘要。ECDF会压缩极端幅度，不能代替原尺度检查 |

## 距离与标记

| 表头/机器列名 | 分子、分母、单位及读法 |
|---|---|
| d1 | 查询县到允许候选中最近一县的特征距离；无量纲，越小越近 |
| d5 | 查询县到第五近县的距离；无量纲，检查是否只有单个相似县 |
| reference_d1_q95 / reference_d5_q95 | 固定训练参照县各自排除自身后的d1/d5的95%分位线；训练专属，添加测试县后不重算 |
| d1_percentile / d5_percentile | 100×(训练参考距离≤查询距离的数量)/训练参考县数。越高表示相对更远；不是相似度百分比，也不是概率 |
| flag_d1 / flag_d5 | 查询距离>相应训练95%分位线+1e-12时为真。因分位插值和经验分布的离散性，不能机械替换成percentile≥95 |
| 超参考线窗口数 /21 | 21个h×日窗口中flag为真的个数；正文同时给分子/分母。其余窗口为假 |
| 频繁超线 | 仅为展示用定义：至少11/21窗口标记，不表示统计显著 |
| max_d1_ratio | 21窗口中d1/q95(d1)的最大值；1.23表示最明显窗口的距离比该窗口参考线高23%，不是误差高23% |
| nearest_fips / nearest_split | 最近一县的行政码及train/test身份；与地理最近县可以不同 |
| test_count_in_top5 | 最近五县中测试县数量，范围0–5，不涉及其未来结果 |
| 平均最近距离缩短% | 每窗口100×(添加前d1−添加后d1)/添加前d1，再对21窗口等权平均。不是RMSE改善百分比 |
| cleared_d1_flag | 添加前超线、添加后在同一个固定阈值下不超线。候选增加本来就可使d1变小，不能直接当成模型提升 |
| 某组/列平方距离贡献 | 查询县与所选最近县的该组/列标准化平方差对总d1²的贡献，只解释距离，不是SHAP、模型特征重要性或因果作用 |

这里的q95是“特征最近邻距离”的参考线，**与Stella用于预测路由的OSI预测值q95门控无关**。

## 参照池与CV列

| scope | 标准化/ECDF由谁决定 | 允许哪些近邻 |
|---|---|---|
| train_loo | 全239训练县 | 当前训练县以外的238训练县 |
| test_to_train | 全239训练县 | 全239训练县 |
| train_plus_test | 与train_loo完全相同 | 其余238训练县+63测试县 |
| oof_before | 对应CV查询县外折之外的训练县 | 同一训练折范围，约191–192县 |
| oof_plus_test | 与对应oof_before完全相同 | 原允许训练县+63测试县，原外折其余县仍排除 |

机器表的cv_seed=0、fold=−1表示“全训练参照”，不是运行了seed0训练。42/20260917/20260918表示各自整套五折CV的输入支持检查，不是单独的一折。

前后比较只在同一scope配对中进行。全训练与OOF的参考阈值不同，不能直接用两列超线数量相减，声称是样本扩充收益。

## 地理距离与范围检查

| 字段 | 定义 |
|---|---|
| geo_d1_km / geo_d5_km | 县代表坐标到最近/第五近参照县代表坐标的球面距离，单位km；不是县界间距，不是电网连接距离 |
| geo_d1_q95_km | 原训练县排除自身后的最近地理距离95%分位线 |
| outside_train_range | 测试县某列是否超出全训练该列min/max；单列范围内不保证联合条件有足够支持 |
| range_excluding_query | 训练案例的单列范围比较必须排除查询县本身；新增测试后仍排除查询县 |

source_cache_rank中Montour的hours_since_peak缺失是“历史没有OSI峰值”的合法状态。敏感性将其编码−1以区别有限ECDF值[0,1]，因此该县的距离受编码选择影响，不能仅凭它宣称数据坏或预测会失败；context不包含此字段。
