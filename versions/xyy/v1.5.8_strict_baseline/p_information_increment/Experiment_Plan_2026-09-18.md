## 5. F2：固定 8 个地理近邻的 20 列摘要

### 5.1 邻居集合的确定规则

本实验的“近邻”是**地理距离最近的县**，不保证与目标县接壤。定义如下：

1. 节点全集为官方 239 训练县与 63 测试县的并集，共 302 县；先按规范后的 FIPS 升序排列。
2. 坐标只取 [c_16ap26.dbf](/home/jacklo/XYY/INFORMS/informs-data-mining-wendyxu/data/geo/c_16ap26.dbf) 的 `LAT/LON`。伴随 PRJ 标明 NAD83 地理坐标；使用这些度数计算球面近似距离，不把经纬度差直接当公里，也不另行投影或学习坐标。
3. 使用 float64 Haversine 距离，固定半径 R=6371.0088 km。经纬度转弧度，公式中中间量裁入 [0,1] 仅用于浮点稳定。
4. 排除自身，以 `(距离, 邻县FIPS)` 排序，取最近 **k=8**。并列距离用 FIPS 升序确定，无随机选邻居。
5. 每县独立选择八个邻居；不额外对称化、不加自环、不叠加接壤边、不限制同州、不按地形、训练标签或历史误差重新选邻居。
6. 聚合等权，每个邻居权重 1/8；不使用距离衰减、用户数权重或可学习边权。距离、经纬度和邻居 FIPS 只存审计表，不加入模型。

最终有 302×8＝2,416 个有向县对。三套 CV、训练和测试使用同一固定邻居表，邻居选择不依赖 fold。不得直接复用 Wendy 的 kNN＋接壤边＋自环图，因为其边集合和权重语义不同。

### 5.2 允许聚合的九个源变量

源数值取 main 项目同一冻结 `v1.5.6` 特征包：训练与测试缓存按县/起点小时组成完整的 302 县视图。只读选择下表白名单，不把整张特征、标签或预测表交给邻居聚合函数。

| 顺序 | 源列 q | 时间/语义 | 新增聚合列数 |
|---:|---|---|---:|
| 1 | last_P_t | 邻县 P71，全部起点固定 | 2 |
| 2 | last_N_t | 邻县 N71，全部起点固定 | 2 |
| 3 | last_D_t | 邻县 D71，全部起点固定 | 2 |
| 4 | last_R_t | 邻县 R71，全部起点固定 | 2 |
| 5 | osi_trend_last6h | 原冻结特征的观测末六小时趋势，全部起点固定 | 2 |
| 6 | gust_t | 邻县在同一预测起点 t 的已提供阵风 | 2 |
| 7 | gust_at_t1h | 邻县在目标 s=t+1 的已提供阵风 | 2 |
| 8 | gust_max_next_6h | 冻结缓存中邻县 `[t,min(t+6,215)]` 的阵风最大值 | 2 |
| 9 | gust_mean_next_6h | 同一窗口的阵风均值 | 2 |

对每个 q，依次追加 `nbr8_mean_{q}`、`nbr8_max_{q}`：

$$\mu_{i,q,t}=\frac18\sum_{j\in\mathcal N_8(i)}q_{j,t},\qquad
m_{i,q,t}=\max_{j\in\mathcal N_8(i)}q_{j,t}.$$

历史五项的 q 不随 t 更新。天气四项必须取邻县在**相同起点 t**的缓存行；`gust_at_t1h` 已经指向目标时刻，不能再 shift 一小时。

最后固定追加两个差值：

| 序号 | 新增字段 | 定义 |
|---:|---|---|
| 19 | self_minus_nbr8_mean_last_P_t | 自身 last_P_t − nbr8_mean_last_P_t |
| 20 | self_minus_nbr8_mean_gust_at_t1h | 自身 gust_at_t1h − nbr8_mean_gust_at_t1h |

共 9×2＋2＝20 列，F2 最终 183 列。差值有助于表达自身相对区域背景的状态和暴露；它们与已有自身值、邻均值存在代数关系，不能单凭 F2 获益就宣称每一列提供独立信息。

**天气窗口保持冻结缓存的实际口径：`next_6h` 包含当前 t，最多七个点，长度为 `min(7,216−t)`。** 不在本实验将它改成六个未来小时。尾部截短沿用原值，原 163 列中的窗口长度/完整性指标仍保留。该口径来自 [v1.5.6 窗口说明](/home/jacklo/XYY/INFORMS/informs-data-mining-2026/versions/xyy/v1.5.6/README1.5.5+1.5.6.md:206)。

本轮新增天气摘要仅用阵风，不同时开展 tp/rain 的一小时时间对齐实验；原有降水列继续保持原基线值。

### 5.3 缺失与边界规则

九列在所有有效 P1h 行都必须完整。均值分母固定为 8，不使用 `skipna`、`nanmean` 或临时减少邻居数来掩盖缺失。

t=215 时 P1h 无有效标签，`gust_at_t1h` 在全部县都为 NaN；F2 中相应的邻均值、邻最大值、自身减邻均值三列允许在这些无效尾行保留 NaN。每列预期缺失数分别为训练 239 行、测试 63 行，且只能出现在 t=215。其余新增列有限。原 163 列本来的合法 NaN 掩码保持不变，不能因为 F2 有三列尾部 NaN 就放宽其他列检查。

若任一有效行少于八个有效邻居、坐标缺失、时间键缺失或历史列跨起点变化，停止预检；不做隐式填补、邻居重选或折内均值回退。

## 6. 跨折近邻为什么不等于标签泄漏

F2 使用的场景是：**302 个参赛县都提供了截至小时 71 的历史及比赛允许的天气，模型预测其中尚无未来标签的县。** 因而某个邻居可以属于外折、内层早停折或官方测试县，但只能贡献这些已经可用的输入。

例如训练县 A 的邻居是外折县 B，A 的特征可以使用 B 的 P71 和已提供天气；不能使用 B 的未来 P、未来 OSI、未来残差、OOF 预测，或由这些量拟合出的统计。

固定边界如下：

| 对象 | 可使用哪些县 | 可使用哪些信息 |
|---|---|---|
| 静态近邻表、无拟合的输入聚合 | 全部 302 县 | 坐标、小时 0–71 历史、允许的天气 |
| a/b 梯度训练 | 当前内层三折或外层四折 | 这些县的合法特征和未来 P 监督 |
| 内层早停 | 外层允许四折中的指定一折 | 该折分支标签，仅用于既定指标选轮 |
| 外层评价 | 留出的整折县 | 训练完成后使用其未来标签评分 |
| 官方测试县 | 不参与任何监督/早停 | 仅提供允许输入；本轮不预测提交 |

不为每个 CV 折删掉其近邻历史，也不根据训练/测试身份改变几何网络；否则特征可用性会随分折变化，偏离本次固定参赛县场景。需要说明的是：这属于已知节点集合、共享可用输入的评价，不等同于一个完全没有历史观测的新地区的泛化测试。

以前的“相似县与未受灾对照”需要排除目标整个 CV 折，是为了防止未来结果参与诊断比较池；本实验的输入聚合不读取任何未来结果，不能把两种用途的排除规则混为一谈。

邻居特征可在 CV 前一次性构建并复用，因为没有拟合步骤或目标统计。若实施中新增任何学习式编码、插补、标准化、目标编码或邻居选择，应视为超出本计划，而不是自动放进全局特征缓存。

## 8. a/b 结构、参数和严格 CV 保持不变

令 p=P71、y=目标 P；a 的支持集为 p>0，标签 `min(y,p)/p`；b 的支持集为 p<1，标签 `max(y−p,0)/(1−p)`。p=0/1 的无贡献分支不参与该分支训练/早停，预测应用值为 0；所有县仍进入最终评分。正支持集中 y=0 的行照常保留。

原始权重分别为 p²、(1−p)²，**每次实际拟合仅用自己的训练支持行计算权重均值并归一为 1**。内层验证用未截断输出上的贡献指标：

$$M_j=\sqrt{\frac{\sum_{r\in V_j}w_{j,r}(f_j(X_r)-y_{j,r})^2}{|V|}}.$$

V 是该内层早停折全部有效 P1h 行，V_j 是分支支持行。权重取原值，分母含无贡献行；`metric="None"`，只有这个自定义指标，`higher_is_better=False`。推理时才将每条分支截断到 [0,1]，按 `p*a_hat+(1−p)*b_hat` 重建；不以 p 作为未来 P 的下界。

| 设置 | 固定值 |
|---|---|
| 模型 / objective | LightGBM / regression（L2） |
| learning_rate / num_leaves / max_depth | 0.05 / 31 / −1 |
| min_child_samples | 50 |
| feature_fraction | 0.8 |
| bagging_fraction / bagging_freq | 0.8 / 5 |
| lambda_l1 / lambda_l2 | 0.1 / 1.0 |
| seed 及全部相关随机 seed | 42 |
| num_threads / deterministic / force_col_wise | 1 / True / True |
| 最大轮数 / 早停耐心 | 2,000 / 100 |

其余设置与冻结 E2 一致并展开写入配置。新增列会改变 `.8` 列采样时的候选集合，分裂与树数可能变化；这属于输入组增量实验，不应解读成信息论上的单列因果证明。本轮不为了保持采样列数而另调 feature_fraction。

每个候选、每个分支、每个外折：外折县完全不参与监督；其余四折轮流三折训练、一折早停；取四次最优轮数均值向下取整（至少 1），再在完整四折上从头重训。两个分支分别选轮，不用外折最终 P/OSI 调轮数，不 warm start 旧模型。

训练集分箱只由当前训练子集建立，验证 Dataset 引用训练 Dataset。保存 `1≤实际树数≤请求轮数`，不要求所有请求轮都生成树。权重、标签、支持集、内层曲线、最佳轮验证预测、来源及实际特征列全部留档。

## 10. 固定输出规则与必须验证的不变量

F0/F1/F2 均继续使用 D_G。分量截断到 [0,1]；OSI 按 `max(0.40P+0.35N+0.25D−0.10R,0)` 重组，沿原规则截断 [0,0.65]、小于 0.001 置零。

C0 是原直接 OSI；C1 是同 horizon 分量重组；C2 用原始直接 OSI 与未做最终后处理的 C1 重组值等权混合后处理；C3 对同县同目标小时的不同 horizon 分量等权对齐后重组。主规则固定 1/6h 用 C3、24/48h 用 C1。

| 相对 F0 的对象 | F1/F2 要求 |
|---|---|
| 原 163 列、P71、监督/支持集/原始权重 | 完全相同 |
| 原始 P6/24/48、D_G 全部 horizon、N/R 全部 horizon | 逐行精确不变 |
| 直接 OSI 和 C0 全部 horizon | 逐行精确不变 |
| C1/C2 的 6/24/48h | 逐行精确不变 |
| C3 的所有 horizon | 均可能改变，必须重算 |
| 主规则 1h、6h | 均可能改变，完整评分 |
| 主规则 24h、48h | 逐行精确不变 |

P1h 在整个预测期间都可能改变，不能把改动误限于预测开始后的一个小时；也不能要求最终 6h 完全不变。

## 11. 评价和解释

主结果始终包含全部 239 县与全部有效行，报告每个 horizon 的 pooled RMSE、SSE、MAE、bias（预测−真实）。四个 horizon 的有效行数仍是 34,177 / 32,982 / 28,680 / 22,944。不可用各折 RMSE 平均替代 pooled RMSE。

必须保存和解释：

1. F1−F0、F2−F0 的全部 C0–C3/主规则结果；F2−F1 作为描述性对照。相对变化统一为 `(候选/参照−1)*100%`，负数改善；参照为 0 时相对值记不可定义。
2. P1h 的重建后、C3 后精度，以及分支贡献、交叉项、截断率、与其他分量误差抵消及 OSI 后处理影响。a/b 分别变好不保证 OSI 变好。
3. 全部县、五个外折和固定目标小时窗口 73–76、77–95、96–143、144–215；保存逐目标小时曲线数据。
4. 固定 P71 分组：p=0、0<p<0.01、0.01≤p<0.1、0.1≤p<0.5、0.5≤p≤1；记录组内县数，避免小组的均值误导。
5. 关注 Forest PA（42053）、Morrow OH（39117）、Brown IN（18013）、Clay WV（54015）、Calhoun WV（54013）、Muskingum OH（39119）、Morgan OH（39115），同时完整保留其他县及所有恶化案例。县名单只用于报告。
6. 县轨迹配对 bootstrap：2,000 次、seed20260910，F1−F0、F2−F0 的主 1/6h、P1h 重建后/C3 后，全部县及固定排除 Morrow 两种口径。抽中县保留整段轨迹，同次抽样对候选一致；区间为 95% 百分位。
7. 检查净 SSE 收益来自哪些县/时段，是否有较多县或全部某一折持续恶化；F2 另报告近邻距离和历史/天气特征的覆盖描述，但不据此选择门控。

官方排名基于各 horizon RMSE 名次平均并在平局时优先 1h。本实验不能推算隐藏榜名次，不把四个原始 RMSE 均值称为官方分数，也不虚构短时加权系数。

两项固定候选是两次预定比较，不能把其中最好的一次及其未经选择校正的区间当作独立确认。三套使用同一批县、同一场事件，且已用于此前开发；重复分折和县 bootstrap 都不能消除空间相关及模型选择偏差。
