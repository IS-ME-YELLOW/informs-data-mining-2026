## 2. 固定20列邻县特征

沿用已核验F2的302县、每县8个地理最近邻（Haversine、排除自身、距离/FIPS排序）、等权均值/最大值。读取其冻结邻居表与坐标，独立核对几何排序；不按标签/残差/CV选择邻居。

每个来源h∈{6,24,48}的九个聚合变量：

1. `last_P_t / last_N_t / last_D_t / last_R_t / osi_trend_last6h`：只来自小时0–71，所有预测起点固定。
2. `gust_t`：相同预测起点t的已提供天气。
3. `gust_at_t{h}h`：相同目标时刻s=t+h的已提供天气。
4. `gust_max_next_6h / gust_mean_next_6h`：原缓存窗口 `[t,min(t+6,215)]`，最多7个点。**不改成h小时窗口，也不改成目标附近窗口。**

每项取8邻县均值、最大值，共18列；再加自身减邻均值的P71、目标阵风两列。字段命名沿用F2，目标天气列名显式含h。没有DEM、新邻居数、距离加权或新增气象变量。

聚合按冻结neighbor rank以float64顺序求和，不用skipna。原163列逐值/列序不变。仅目标天气的邻均值、邻最大值、差值三列在t+h>215的无效尾部允许NaN；有效预测行所有新增特征必须有限。

三个特征包覆盖训练239县34,416行与测试63县9,072行。测试县只提供许可历史和天气作邻居输入，本轮不做测试模型推理或提交。中心平滑N71/R71使用官方给定值，不读取隐藏小时72停电重算。
