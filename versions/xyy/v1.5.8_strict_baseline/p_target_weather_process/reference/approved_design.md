# 短时增长与长期暴露：依据和具体实验设计

状态：本轮只分析与提出可执行设计，没有训练这两个实验。以下是一套建议冻结的首轮参数与比较，不代表这些参数已经通过验证，也不把此前反复查看的同事件CV当成全新独立测试。所有模型改动仍应在后续明确启动训练时实施。

## 1. 两个方向各自解决什么问题

共同误差调研中，Forest在三套CV单县贡献1h SSE约31%–35%，但截止前已有P69≈.0083→P70≈.1430、N71≈.0654的增长状态；N71超过对应训练折最大值。现有P1 a/b按初始停电存量P71缩放，尚未把已知增长幅度作为输出尺度。仅重复添加N71或末6小时趋势没有新信息。

Clay/Calhoun/Braxton有相似受灾县，但P/D的幅度与持续量共同低估。Muskingum在两套分折过高估计持续量、在另一套已较准，说明需要区分增长/恢复阶段并检查分折敏感性，不能统一放大所有高风险县。其具体物理原因尚未因果确认。

两项都是归纳偏好/特征表达假设。匹配距离或误差大，不能直接证明某种改动有效；测试输入是否离群也不能代替模型效果验证。

- 小时0为2026-03-11 00:00，停电观测截止71；预测起点t为72–215，目标s=t+h，距截止时间τ=s−71。

## 3. 实验A：已知增长尺度进入P1的增量分支

### 当前参照

最新P1仍是两个分支：P_hat=p*a_hat+(1−p)*b_hat，a/b分别截断[0,1]。a/b是相对于初始水平的数学分解，不是客户群的真实存续/故障概率。训练监督满足a=min(y,p)/p、b=max(y−p,0)/(1−p)。

当前结构擅长把较高p传到输出，但对p仅中等、g异常高的县，新增部分仍由(1−p)缩放，可能没有利用增长尺度外推。主实验仅换b分支，a预测复用同CV的最新P1 a模型，避免两条分支一起变化。

### 建议首轮只比较三个候选

统一作用于τ≤24的P1来源，即s=73–95；τ>24明确逐行使用原P1预测。该24小时边界是首轮探索性时间范围，不声称是普适物理常数。

| 候选 | 新拟合内容 | b监督与重建尺度 | 用途 |
|---|---|---|---|
| G0 当前参照 | 无 | 原a/b＋F2 | 完整参照 |
| G1 早期b对照 | 仅用相同早期窗口重训b | s0=1−p；u0=max(y−p,0)/s0 | 隔离仅缩小训练时间范围的效果 |
| G2 增长尺度候选 | 同G1的行、特征与树参数重训b | sg=(1−p)*(1+g/.01)；ug=max(y−p,0)/sg | 检验增长尺度归一化与重建这一整体改动 |

这里s0/sg表示输出尺度，和目标小时s不同，代码应分别命名scale_base/scale_growth，避免混淆。常数.01是1个百分点的官方N数值尺度，首轮固定，不在本CV搜索多个常数。

G1/G2早期推理：

```text
increment = clip(scale * clip(b_model(X), 0, 1), 0, 1-p)
P_new = clip(p * a_reference(X) + increment, 0, 1)
```

- p=1时增量恒为0，b训练支持集排除此类行；不通过epsilon修改分母。p=0正常处理。
- G2的scale≥1−p，所以监督ug仍在[0,1]。它允许同一个归一化响应在更高已知增长状态下产生更大绝对增量，最终仍受P≤1约束。
- 单纯换单位不保证提分：若模型能精确学到原条件均值，缩放与反缩放会抵消。希望获得的是有限容量树、正则和训练支持不足时更合适的幅度泛化；不是预设N71大就必然持续增长。
- 不施加P≥p的下界，不强制P单调上升；a仍可以表达初始水平以内的下降。
- g=0时两种尺度相同，但重新训练后的模型参数不同，预测不保证相同。只有τ>24明确复用G0，才保证该部分不变。
- 时间边界可能产生跳变，需要列为预先检查项；不能看过OOF后临时改变窗口或添加平滑权重。

### 训练损失和严格隔离

G1/G2均用L2拟合u，原始权重为scale²，使误差按P增量尺度衡量。每次拟合只用该次训练行计算权重均值并归一化；验证折不参与尺度统计、分箱、训练或正则归一化。尺度公式本身只依赖已知p/g。

内层早停指标为 sqrt(sum(scale²*(f−u)²)/n_valid_all)，采用原始权重、原始模型输出、同一有效验证行分母；p=1的无增量行贡献0但计入分母。四次三折训练/一折早停选轮后，在外层剩余四折重训，再预测完全未参与训练和选轮的外折。

内层选轮只评估b的贡献误差，不拿已保存的外层a模型拼成内层P/OSI选轮：该a模型可能见过当前内层验证县标签。保存的a仅用于对应外折的最终合成，且必须证明未见该外折标签。这样不需要为了b实验重新拟合内层a，也不引入依赖泄漏。

每个候选每CV为20次内层探测＋5次外层重训；seed42的G1/G2合计50次拟合、10个新外层模型。当前a模型仅复用，不重新训练；其他分量和直接OSI来源均冻结。

### 作用范围与判定

- 源改动只有P1的s=73–95。通过C3，影响最终1h的73–95以及6h的78–95；24h/48h有效目标从96/120开始，因此最终长期输出应精确不变。
- 保存G2−G1（增长尺度整体增量）、G1−G0（早期b专门训练）和G2−G0（净改进），不能只报告最好的一项。
- 主看完整1h pooled RMSE，同时报告完整6h、分量P、各县、早期/后期、g=0和g>0等允许状态组。后期/长期逐行不变量必须通过。
- Forest是预先指定诊断对象，不是路由开关；Morrow、Muskingum以及已知增长但未来轻微受灾的县必须同样检查。
- 不把P分支损失改善直接当成OSI改善；P与N/D/R误差交叉项保留。G2是否优于G1/G0，必须由结果决定。
- seed42若无有意义净增量或代价明显，就停止；若有值得确认的方向，保持全部定义不变再做另外两CV。无法识别的孤立事件不通过县级规则强行修补。

## 4. 实验B：以目标时刻为基准的天气顺序与恢复阶段代理

### 与现有特征的实质区别

核对code_phase1/features.py：累计暴露从小时48累计到预测起点t；gust_at_t+h只提供目标瞬时值；next_h在[t,t+h]聚合；peak4h取最高4个点、不要求连续；storm_phase按日期为所有县赋同一阶段。已有最大/均值/累计/部分变化率，不能将它们改个名字算成新信息。

例如两段天气[10,50,50,10,10,10]与[10,10,10,50,50,10]的峰值、均值、阈值小时数和首尾值相同，但暴露距离目标时刻的远近不同。旧特征中的部分变化率能帮助区分某些情形，仍没有直接表达下面的目标前过程。

### 建议首轮固定8个候选字段

目标s前的窗口为u∈[s−47,s]，共48个小时；本项目所有有效目标s≥73，因此窗口完整。令e_u=max(gust_u−30,0)，H_u=1[gust_u>30]，阈值30mph沿用既有口径，不搜索阈值。

| 新字段 | 明确定义 | 要表达什么 |
|---|---|---|
| exposure_decay_6h | sum(e_u*exp(−(s−u)/6))/sum(exp(−(s−u)/6)) | 更偏重刚发生的暴露 |
| exposure_decay_24h | 同式，衰减时间改为24 | 较长时间尺度的暴露记忆 |
| hours_since_last_high_gust | s−max(u:H_u=1)，窗口无强风则49 | 最近强风过去多久 |
| has_high_gust_48h | 窗口中是否存在H_u=1 | 区分“没有强风”与普通间隔 |
| high_gust_episode_count_48h | H_u连续为1的段数；跨窗口左边界的段算1段 | 一轮连续暴露或多次再增强 |
| max_lull_between_episodes_48h | 两个强风段之间连续H=0的最长长度；不足两段为0 | 两轮之间是否有间歇 |
| exposure_weighted_age_48h | sum((s−u)*e_u)/sum(e_u)，总暴露0时49 | 暴露发生在较早还是较晚 |
| recent6_exposure_fraction | sum(e_u,u=s−5..s)/sum(e_u,u=s−47..s)，分母0时0 | 暴露是否重新集中到最近6小时 |

这是从已有许可天气提取的新表示，不是新增观测来源。“恢复阶段”仅是暴露结束后间隔的代理，不是已经知道实际恢复速度；不能放入未来outageCount、实际修复时长或事后电力公司恢复进度。

### 对照与训练范围

- W0：最新T的P24直接Huber＋邻县183列，其他来源冻结。
- W1：只给同一个P24模型增加上述8列，共191列；目标、损失、正则、CV、seed均不变。首轮不同时修改P结构或N/D/R。
- seed42新增25次拟合、5个外层模型。输入按每个原点t的目标s=t+24构造，而不是误用t的暴露年龄；其他候选horizon不顺带训练。
- 内层只按P24本身的冻结指标选轮，不用含原外层N/D/R模型的内层OSI选择轮数；完整OSI用于外折评价。
- 主比较完整最终24h RMSE，必须同时报告通过C3影响的1/6h及不变的48h。短时目标96以前应精确不变。
- 对照Clay/Calhoun/Braxton的低估，也检查Muskingum等过高持续预测；固定这些诊断对象不等于按县选择输出。
- 先核对字段是否与现有列逐行相等/高度冗余以及关键过程是否确有变化，再训练。若无增量，不继续在同OOF搜索大量阈值、衰减时间或窗口。

## 5. 如何使用本轮测试支持分析

测试县特征离群只用于判断训练覆盖风险和固定诊断分组，不使用测试标签挑超参数。找到与Forest/Morrow相似的测试县，说明输入状态存在跨县复现，不证明已有正确未来监督，也不保证G2能改善测试RMSE。

如果某类严重状态在训练中只有极少县，即使测试中有相似输入，CV依然需要严格隔离，不能将测试县伪标签当作新事实。严谨实验应先检验跨训练县的泛化；输入覆盖分析与模型增益验证分别给出结论。
