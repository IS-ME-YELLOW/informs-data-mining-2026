## 八列定义与合法信息

小时0为2026-03-11 00:00，停电观测截止71。新特征函数只接收县码/小时/gust及预测键；不接收P/N/D/R、目标、残差或县误差名单。天气使用官方已提供序列，不增加新的天气数据。

对目标s=t+24≤215，取u=s−47..s（恰好48点，包含目标时刻）。e_u=max(gust_u−30,0)，H_u=1[gust_u>30]，age=s−u。所有有效s≥96，窗口完整。无法评分的s>215，新增8列均NaN；这些行不进入拟合/选轮。

| 新字段 | 定义 | 单位/边界 |
|---|---|---|
| exposure_decay_6h | sum(e_u exp(−age/6))/sum(exp(−age/6)) | mph；6为衰减时间常数，不是截断长度 |
| exposure_decay_24h | 同式，常数24 | mph；窗口仍为48点 |
| hours_since_last_high_gust | 最近H=1的age | 小时；没有强风时49是缺省编码，不代表实测49小时 |
| has_high_gust_48h | 是否有H=1 | 0/1 |
| high_gust_episode_count_48h | H连续为1的段数 | 整数；左边界跨入的一段计1，不等于真实风暴次数 |
| max_lull_between_episodes_48h | 两个强风段之间最长连续H=0长度 | 小时；不足两段为0；首尾空白不计入段间间歇 |
| exposure_weighted_age_48h | sum(age e_u)/sum(e_u) | 小时；分母0时49 |
| recent6_exposure_fraction | 最后6点e_u之和/48点e_u之和 | [0,1]；分母0时0 |

使用float64，按时间先后顺序构造；指数权重用math.exp，聚合用math.fsum避免平台求和顺序差异；不对输出特征另行四舍五入。这是新8列的数值约定，旧183列不变。

“恢复阶段”只是天气结束后时间等代理，不读取实际未来修复进度。先做输入预检和冗余描述，不能看成绩后删列、改阈值、换窗口或增加候选。
