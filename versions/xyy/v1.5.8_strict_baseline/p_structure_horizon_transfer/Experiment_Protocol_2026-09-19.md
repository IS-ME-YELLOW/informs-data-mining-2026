## 2. 原E2定义原样迁移

对每个县始终使用合法历史p=P71，与163列缓存last_P_t逐值核对；即使起点t较晚，也不能更新成真实P_t。未来目标y=P_(t+h)，h取6/24/48：

```text
a = min(y,p)/p                     仅p>0，原始权重p²
b = max(y-p,0)/(1-p)              仅p<1，原始权重(1-p)²
P_hat = p*clip(a_hat,0,1) + (1-p)*clip(b_hat,0,1)
```

p=0时a不参与训练/早停，原始输出保存NaN、应用值固定0；p=1时同样处理b。无贡献分支不影响全县评分覆盖。不得加epsilon、P≥p下界、单调恢复约束、两分支互斥或按未来y筛行。

新a/b模型只读原163列特征及列序，不迁移F2的20个邻县特征，不移动天气或改变目标时刻天气定义。原163列本身包含各horizon目标天气，保持原数值和许可范围。

## 3. 严格训练与权重

- 五折按县；每外折在其他四折中做四次3折训练/1折早停，best_iteration均值向下取整，再用完整四折重训。外折不参与分箱、梯度、早停或轮数选择。
- 先按允许折、有效目标和p支持条件选行，再读取该范围内的未来P构造监督。
- 权重先用该次训练子集的原始权重均值归一化；验证Dataset使用同一个训练均值，refit重新用完整允许范围均值。不能使用验证/外折统计来归一化训练权重。
- 两分支均使用原E2的LightGBM L2参数：2000轮上限、早停100、其他参数/正则/种子不变，单线程deterministic。
- 关闭内置metric，早停用原E2的P贡献RMSE：`sqrt(sum(w_val*(raw_pred-y_branch)^2)/n_all_valid_val)`。分母是该验证折全部有效P行，包括该分支不支持的零贡献行；不使用LightGBM默认加权RMSE分母。
