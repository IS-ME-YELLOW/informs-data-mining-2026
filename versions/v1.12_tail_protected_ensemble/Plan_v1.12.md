# v1.12 尾部保护融合计划

日期：2026-09-13

## 假设

v1.11 显示六路树模型平均能改善普通样本和 MAE，但会伤害高 OSI 尾部。预先固定一个最小门控：t+1/t+6 保留 v1.8；t+24/t+48 在 v1.8 正预测的内层 q95 以下用六路简单平均，以上回退 v1.8。

## 评估协议

- v1.5.6 的 163 列特征，`balanced_v1` 县级五折，`seed=42`。
- 每个外层折的 q95 仅由另外四折的 v1.8 预测计算；门控输入不含真实标签。
- 与 v1.8 比较 RMSE、MAE、逐折方向、逐县 paired bootstrap 和真实高 OSI 子集。
- 晋级要求：目标 horizon RMSE 至少改善约 0.5%、至少 4/5 折改善、bootstrap RMSE 差上界低于 0，且其他 horizon 不退化。
- 保存 20 个外层模型、4 个最终测试模型、OOF、测试预测、提交、哈希与独立重载结果。

## 状态

已完成并通过预设晋级指标。需要注意，q95 规则来自 v1.11 OOF 诊断，因此这是严格外折计分下的当前最佳内部候选，但并非一份完全未参与方向选择的独立确认集。
