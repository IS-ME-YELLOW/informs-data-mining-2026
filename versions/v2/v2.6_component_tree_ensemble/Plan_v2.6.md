# v2.6 分量树模型融合实验计划

日期：2026-09-13

## 目标

对每个 horizon 的 P/N/D/R 分别融合 v1.8 LightGBM、v2.4 XGBoost、v2.5 CatBoost OOF，再按官方公式重组 OSI：

`max(0, 0.40*P + 0.35*N + 0.25*D - 0.10*R)`，随后截断至 `[0,0.65]` 并将 `<0.001` 置零。

固定 v1.5.6、`balanced_v1`、`seed=42` 和已有缺失掩码。基础模型目录只读。

## 方法与无泄漏约束

- 分量层比较三模型简单平均、非负凸融合和向 LightGBM 分量预测回退的安全凸融合。
- 每个 component/horizon/外折的权重与安全系数只用其余四折学习；外折县不参与学习。
- 全 OOF 最终权重仅生成测试预测和提交，不作为 OOF 评估。
- P/N/D/R 先截断至 `[0,1]`；只有重组 OSI 后才执行 OSI 置零与上界规则。

## 重点诊断

- P、D：总体及逐折/逐县 RMSE。
- N、R：真实零值、正值和正值前 5% 尾部的 RMSE/MAE。
- 重组 OSI：相对 v1.8 的 RMSE/MAE、方向一致性、县级 paired bootstrap、高 OSI 与 t+48。
- 保存 80 个外折模型、16 个最终模型、全部 OOF/测试预测、权重、指标、哈希和独立重载验证。

## 执行状态

已完成。逐分量融合改善多数 MAE，但重组 OSI 的四个 RMSE 均未超过 v1.8，故不晋级。
