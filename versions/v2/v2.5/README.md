# v2.5：v1.5.6 特征上的 CatBoost 分量基线

日期：2026-09-11。

本版沿用 v2.3 的分量路线，把输入更新为 v1.5.6 的 163 列，并读取 v1.10 元数据作为同族直接 OSI 对照。最大轮数为 4,000，早停耐心 100。

## 合成 OSI 的池化 OOF 结果

| Horizon | RMSE | MAE | RMSE 相对 v1.10 | MAE 相对 v1.10 |
|---|---:|---:|---:|---:|
| t+1h | 0.012087 | 0.003375 | -1.16% | -1.53% |
| t+6h | 0.010940 | 0.003231 | +2.08% | -3.24% |
| t+24h | 0.008527 | 0.002622 | -1.80% | -4.11% |
| t+48h | 0.007703 | 0.002037 | -2.43% | -4.16% |

四个 MAE 均改善；RMSE 在 t+1/t+24/t+48 改善，但 t+6 回退 2.08%，因此不应统一以分量 CatBoost 替代直接模型。相对旧 v2.3，RMSE 变化为 `-0.98% / +0.25% / -0.02% / +0.74%`。

80 个折中只有 2 个最佳轮数超过 2,000，最大为 2,927，没有折接近 4,000。曾尝试把上限直接设为 8,000，但 CatBoost 在 t+1/P_t/fold2 训练前因内部内存预分配报 `bad allocation`；改回 4,000 后该折在 1,185 轮正常完成，证明错误来自过高上限的资源压力而非数据。4,000 是本机上足够且更稳妥的设置。

新增列中 `tp_rate_next_24h` 是 t+24/P_t 的第 3 特征，`pct_forest_classified` 是 t+48/R_t 的第 2 特征，窗口归一化和土地覆盖质量列在多个分量中进入前十。
