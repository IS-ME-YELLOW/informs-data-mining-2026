# Stella v1.12 方法设计与实现补充说明

## 1. 文档目的与证据边界

本文补充说明 Stella v1.12 strict 的设计动机、正式方法、实现参数和计算成本，不新增实验，也不改变已经冻结的协议。实验结果见[《三套分折复现结论》](三分折复现结论.md)，完整协议见[《Experiment Contract》](../stella_v112_handoff/Experiment_Contract.md)。

需要区分三种说法：

- **预先固定的经验选择**：三类树、直接/分量两种建模路径、六路等权平均、q95 阈值和门控方向。它们有历史诊断或工程理由，但不是理论最优解。
- **本轮实验直接支持的结论**：固定方案 L2 在三套分折的 24h、48h 上相对 L0 的 6 个 RMSE 差点估计全部为负，且 L2 相对 L1 的 6 个方向也全部改善。
- **本轮实验不能支持的结论**：不能声称任一单独设计要素最优，不能声称每项结果均达到统计显著，也不能把重复分折当作新的独立县样本或外部测试集。

## 2. 设计动机与选择过程

| 设计 | 为什么这样选 | 依据类型 | 不能据此声称什么 |
|---|---|---|---|
| LightGBM、XGBoost、CatBoost 三类树 | 在同一套 163 列表格特征上引入不同的梯度提升树实现，同时复用此前已有的 Stella 树模型路线，避免本轮再扩大模型搜索空间 | 工程经验和既有实验路线；三类方法本身分别见原始论文 | 没有在最终严格协议下做“三类对两类/一类”的消融，不能说三类组合理论上或实验上全局最优 |
| direct 与 component 两种路径 | direct 直接学习最终 OSI；component 分别学习 P/N/D/R，再用既定 C1 公式合成 OSI。两条路径表达同一目标的两种构造方式 | 继承 v1.8—v1.11 的已有建模结构；本轮保留六路单模型诊断 | 最终 L2 的改善不能单独归因于 component 分解，也不能证明 C1 系数最优 |
| 六路等权平均 | 每个已处理 OSI 来源只占 `1/6`，不再用当前 OOF 学习权重，可减少新的调参自由度和选择偏差；规则简单且容易复现 | 预先固定的经验选择；v1.11 显示平均对 MAE/普通样本有帮助，但对高 OSI 尾部 RMSE 有风险 | 等权不是由优化或定理推出，也没有证据证明优于所有非等权组合 |
| q95 尾部回退 | v1.11 的 OOF 诊断发现：无条件平均会损害高 OSI 尾部。于是对 L0 的高预测尾部保留 L0，其余位置使用平均，尽量只保护少量高风险行 | q95 和门控方向在本轮前固定；来自[v1.11 诊断](../v1.11_tree_ensemble/README.md)和[v1.12 计划](../v1.12_tail_protected_ensemble/Plan_v1.12.md)；本轮三分折结果支持完整 L2 方案 | q95 不是理论保证，也没有与 q90/q97.5 等阈值做本轮搜索；不能包装为最优分位数 |
| 1h/6h 不改，只研究 24h/48h | 隔离“长期融合”假设，避免把已经验证的短期 F2 与长期改动混在一起 | 冻结实验协议 | 本轮不提供新的短期模型证据 |

三类树和六路结构的目标是获得有限的模型差异，而不是以“模型数量更多”作为升级理由。v1.11 实际观察到六路残差高度相关，因此它们并非六个独立信息源；这也是本轮不学习复杂权重、只测试预先限定浅门控的重要背景。

## 3. 可发表的方法定义

### 3.1 数据、分折与记号

训练集包含 239 个县、34,416 行和冻结的 163 个输入特征。交叉验证在县级进行，同一县的完整时间轨迹只能属于一个折。三套预注册分折种子为 42、20260917 和 20260918；模型随机种子固定为 42。三套分折使用同一批县，仅改变县到折的分配。

令预测时距为 $h\in\{24,48\}$，五个县级折的集合为 $F=\{0,1,2,3,4\}$。对待评分外折 $q$，可用于训练和内部选择的折为 $S=F\setminus\{q\}$。对预测向量 $x$，定义后处理：

\[
\operatorname{post}(x)=
\begin{cases}
0, & \operatorname{clip}(x,0,0.65)<0.001,\\
\operatorname{clip}(x,0,0.65), & \text{otherwise}.
\end{cases}
\]

阈值比较是严格小于 0.001 才置零，因此恰好等于 0.001 的值保留。

### 3.2 六路预测来源

六路顺序固定为：

1. `lgbm_direct`
2. `lgbm_component`
3. `xgboost_direct`
4. `catboost_direct`
5. `xgboost_component`
6. `catboost_component`

对任一家族 $f\in\{\mathrm{LGBM},\mathrm{XGB},\mathrm{CatBoost}\}$：

- direct 路直接拟合 `osi_target_t{24,48}h`，处理后的来源为
  \[
  s_{f,d}=\operatorname{post}(\widehat{OSI}_{f,d}).
  \]
- component 路分别拟合 `P_t`、`N_t`、`D_t`、`R_t` 对应时距的四个目标。先将四个原始预测分别截断到 $[0,1]$，再按 C1 合成：
  \[
  z_f=\max(0,\ 0.40\widehat P_f+0.35\widehat N_f+0.25\widehat D_f-0.10\widehat R_f),
  \qquad s_{f,c}=\operatorname{post}(z_f).
  \]

因此，一条 component 来源是四棵分量树合成后的一个 OSI 预测，不是把四棵分量树分别当作四个等权成员。

### 3.3 L0、L1 与门控候选 L2

长期基线为 LightGBM component C1：

\[
L0=s_{\mathrm{LGBM},c}.
\]

六路简单平均后再次后处理：

\[
L1=\operatorname{post}\left(\frac{1}{6}\sum_{j=1}^{6}s_j\right).
\]

对每个外折 $q$ 和时距 $h$，严格内层程序产生阈值 $\theta_{q,h}$。最终候选为：

\[
L2_i=
\begin{cases}
L0_i, & L0_i>\theta_{q,h},\\
L1_i, & L0_i\leq\theta_{q,h}.
\end{cases}
\]

等于阈值时使用 L1。门控只读取 L0 的预测值，不读取该行真实标签；事后计算的“真实 top 5%”只用于诊断，不参与门控。

> **术语提醒：**本文的 **L2** 只是“第二层候选方案”的名称，不是 L2 损失、平方误差或 L2 正则化。LightGBM 的 `lambda_l2`、XGBoost 的 `reg_lambda` 和 CatBoost 的 `l2_leaf_reg` 才是各学习器的 L2 正则参数。论文正文建议始终写成“候选 L2（gated candidate）”，不要单写“采用 L2”。

### 3.4 实际训练损失与选轮指标

令残差 $e=y-\hat y$。三类学习器的**训练目标并不相同**，但早停选轮都使用 RMSE：

\[
\operatorname{RMSE}=\sqrt{\frac{1}{n}\sum_{i=1}^{n}(y_i-\hat y_i)^2}.
\]

- **LightGBM 4.7.0**：`objective=huber`，代码未覆盖 `alpha`，因此使用该版本默认值 `alpha=0.9`；其 Huber 截断参数为 0.9，即
  \[
  \ell_H(e)=
  \begin{cases}
  \tfrac12e^2,& |e|\leq0.9,\\
  0.9|e|-\tfrac12(0.9)^2,& |e|>0.9.
  \end{cases}
  \]
  选轮指标为 `rmse`。
- **XGBoost 3.2.0**：`objective=reg:pseudohubererror`，`huber_slope=0.01`。对应伪 Huber 形式为
  \[
  \ell_{PH}(e)=\delta^2\left(\sqrt{1+(e/\delta)^2}-1\right),\quad \delta=0.01.
  \]
  选轮指标为 `rmse`。
- **CatBoost 1.2.10**：`loss_function=Huber:delta=0.01`，即
  \[
  \ell_H(e)=
  \begin{cases}
  \tfrac12e^2,& |e|\leq0.01,\\
  0.01|e|-\tfrac12(0.01)^2,& |e|>0.01.
  \end{cases}
  \]
  选轮指标为 `RMSE`。

这里的“Huber/伪 Huber 训练目标”和“RMSE 早停与最终评分”应分别报告，不能把 RMSE 写成三类模型共同的训练损失。

### 3.5 外层模型的严格选轮

对每个外折 $q$、模型家族和目标：

1. 对每个 $v\in S$，只用 $S\setminus\{v\}$ 拟合探测模型，并只在 $v$ 上早停，记录正整数最佳轮数 $b_v$。
2. 固定最终轮数
   \[
   B=\max\left(1,\left\lfloor |S|^{-1}\sum_{v\in S}b_v\right\rfloor\right).
   \]
3. 用完整 $S$ 和固定轮数 $B$ 重新拟合，不再传入验证集或早停，然后预测外折 $q$。

因此，外折 $q$ 的标签既不参与参数拟合，也不参与早停和轮数选择。

### 3.6 q95 的严格内层生成

阈值不能从全局 OOF 删除外折后直接计算，因为产生其他折 OOF 的旧模型仍可能在训练或早停时接触过外折 $q$。本实验为每个 $(q,h)$ 单独生成内层预测：

1. 对每个内层被预测折 $r\in S$，令 $T=S\setminus\{r\}$，此时 $|T|=3$。
2. 对 LightGBM 的 P/N/D/R 四个分量，分别在 $T$ 内做三次“两折训练、一折早停”，对三个最佳轮数取 floor 均值，再用完整 $T$ 固定轮数重训并预测 $r$。
3. 用 C1 公式合成 $r$ 的 anchor 预测。该预测的模型构造没有使用 $q$ 或 $r$ 的标签。
4. 拼接四个 $r$ 的有效时距预测，只保留严格大于零的 anchor 值，并计算：
   \[
   \theta_{q,h}=Q_{0.95}\bigl(\{a_i:a_i>0\}\bigr),
   \]
   其中实现为 `np.quantile(..., 0.95, method='linear')`。

这个嵌套过程把阈值生成也包含在外层隔离中，用来防止模型选择信息从外折标签泄漏。它控制的是评估流程中的选择偏差风险，不构成对未来分布的理论保证。

## 4. 实际实现参数

所有学习器均使用 CPU；每个单模型拟合固定为单线程。XGBoost 和 CatBoost 输入转为 `float32`，LightGBM 使用冻结表中的数值类型；没有新增类别编码。

| 学习器 | 最大探测轮数 | patience | 已显式固定的参数 |
|---|---:|---:|---|
| LightGBM direct/components | 2000 | 100 | `learning_rate=.05`, `num_leaves=31`, `max_depth=-1`, `min_child_samples=50`, `feature_fraction=.8`, `bagging_fraction=.8`, `bagging_freq=5`, `lambda_l1=.1`, `lambda_l2=1`, `num_threads=1`, `force_col_wise=True`, `deterministic=True`; 五个相关 seed 均为 42 |
| XGBoost direct | 4000 | 100 | `learning_rate=.05`, `max_depth=6`, `min_child_weight=50`, `subsample=.8`, `colsample_bytree=.8`, `reg_alpha=.1`, `reg_lambda=1`, `tree_method=hist`, `random_state=42`, `n_jobs=1`, `verbosity=0` |
| XGBoost components | 8000 | 100 | 与 XGBoost direct 相同，仅最大探测轮数不同 |
| CatBoost direct/components | 4000 | 100 | `learning_rate=.05`, `depth=6`, `l2_leaf_reg=3`, `random_strength=1`, `rsm=.8`, `random_seed=42`, `thread_count=1`, `allow_writing_files=False`, `verbose=False` |

XGBoost 和 CatBoost 的早停索引从 0 开始，保存为轮数时加 1；LightGBM 的 `best_iteration` 已是轮数。最终重训不保留早停开关。实际配置见 [`resolved_config.json`](resolved_config.json)，拟合实现见 [`src/models.py`](src/models.py)。未显式覆盖的库默认参数没有被逐项序列化，本文不对其作事后推测；需要完全复算时应使用冻结版本、配置、源码和每个模型的 receipt。

## 6. 训练、推理与存储成本

### 6.1 每套分折的固定拟合预算

| 项目 | 新拟合次数 | 新保存模型 |
|---|---:|---:|
| XGBoost/CatBoost 外层模型：100 个任务，每个 4 次探测 + 1 次重训 | 500 | 100 |
| LightGBM 内层 anchor：80 个任务，每个 3 次探测 + 1 次重训 | 320 | 80 |
| 引用同分折 strict baseline 的 LightGBM 外层模型 | 0 | 0（引用并验证 50 个） |
| **合计** | **820** | **180** |

每套分折均保存 180 个新模型，并在独立验证时重载这 180 个模型和 50 个引用模型；保存预测与重算预测的最大绝对差均为 0。

820 次是每套分折成功产物对应的正式拟合调用数。确认分折采用过分片/续跑，若中途退出的进程曾完成但未留下正式 receipt，其额外重复计算没有完整日志，不能加入精确调用总数。

## 7. 推荐的论文表述

可以写：

> 我们在固定的县级嵌套交叉验证协议下，比较长期 LightGBM 分量基线、六路等权平均及一个预先指定的尾部门控候选。门控阈值完全由相应外折之外的严格内层预测生成。该候选在三套重复县级分折的 24h 和 48h 上均获得负的 RMSE 差点估计，但三套分折共享同一批县，且部分单分折 bootstrap 区间跨零，因此结果被解释为跨分折的方向复现，而非独立外部验证或理论保证。

不建议写：

> 三种树理论互补，等权是最优权重，q95 是最优阈值，L2 已被证明普遍显著优于基线。
