# v1.10：v1.5.6 特征上的直接 OSI CatBoost 基线

日期：2026-09-11。

本版保留 v1.7 的 CatBoost 参数、`balanced_v1` 县级五折、seed=42、Huber 损失和 OSI 后处理，将输入更新为冻结的 v1.5.6 163 列特征。最大轮数由 2,000 提高到 4,000，早停耐心保持 100。

## 池化 OOF 结果

| Horizon | RMSE | MAE | 五折最佳轮数 | 全量轮数 |
|---|---:|---:|---|---:|
| t+1h | 0.012228 | 0.003427 | 895 / 305 / 588 / 325 / 369 | 496 |
| t+6h | 0.010717 | 0.003339 | 385 / 1195 / 1236 / 1145 / 511 | 894 |
| t+24h | 0.008683 | 0.002735 | 671 / 1261 / 1273 / 126 / 622 | 791 |
| t+48h | 0.007895 | 0.002125 | 440 / 25 / 611 / 29 / 731 | 367 |

相对旧 v1.7，RMSE 变化为 `+0.40% / -2.01% / +0.17% / +1.39%`。新增的 `tp_rate_next_24h` 在 t+24 特征重要性排第 3、占比约 7.70%，`tp_rate_next_48h` 在 t+48 排第 14，说明窗口质量特征对 CatBoost 的影响比对直接 XGBoost 更集中，但也没有带来全 horizon 一致提升。

20 个折的最大最佳轮数为 1,273，没有折超过 2,000；4,000 上限充足，直接 CatBoost 实际不受旧上限限制。
