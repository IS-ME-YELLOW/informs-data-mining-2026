## 3. Newton：具体是哪条路径在放大

对象是外层 fold 2 的 1h 检查点 `gat_component_v158_t01h_S0-1-3-4.pt`。Newton County, Indiana，FIPS=18111，不在该模型监督训练 scope 内。

该模型的计算可以写成：

```text
x = 使用训练 scope 的 mean/std 标准化后的 205 维输入
s = skip(x)                         # 直接线性映射为 24 维
m = ELU(GAT2(ELU(GAT1(x, graph))))  # 两层图消息路径，24 维
correction = residual_scale × head(m + s)
prediction = 后处理(base + alpha × correction)
```

这里 `skip` 是绕过 GAT 消息层的神经网络直接路径，不是树基线本身；树基线通过最后的 `base + alpha × correction` 保留。图输入本身含近邻摘要，因此“关闭消息路径”也不等同于从输入中删除全部空间信息。

Newton 的 `pre_event_mean_osi` 是已知早期历史平均值 **0.3865375**；该训练 scope 均值约 0.00120165、标准差约 0.00251136，标准化后为 **153.437**。它是合法历史输入，但远超监督训练支持范围，不能把这个数值大直接解释为未来泄漏。

### 3.1 固定权重的路径干预

下表平均值均取 Newton 的 **143 个有效 1h 行**；保持原权重、原 residual_scale、原 α=0.2 和后处理。这里只报告该县的计算敏感性，不将其当成新 CV 成绩。

| 固定权重下的操作 | 平均原始 OSI 校正 | 平均最终预测 |
|---|---:|---:|
| 原模型 | +1.031726 | 0.210178 |
| 将整个 skip 路径输出置零 | −0.005668 | 0.002870 |
| 将整个图消息路径输出置零 | +1.342119 | 0.272256 |
| 两路径都置零，仅保留 head 的零输入输出 | −0.001095 | 0.003658 |
| 仅在 skip 路径移除 Newton 的 pre_event_mean_osi 偏离均值项 | −0.172059 | 0 |
| 仅在消息路径移除该项 | +1.061611 | 0.216155 |

**在这组固定权重和输入下，skip 路径是大幅正校正的主要来源；消息路径并没有制造这次巨大正偏移，反而减轻了偏移。** 这不能推广为“所有图消息都有益”或“邻县信息的独立贡献已证实”：消息路径也处理本县信息，与另一条路径共同训练。

不能将两个单独路径的输出直接相加，因为它们之后还有非线性 head。为此，另以两条路径为两个参与者，对两种移除顺序取平均，得到精确相加的两参与者 Shapley 分解：

```text
head 零输入的基准输出          −0.001095
skip 路径贡献                 +1.190304
消息路径贡献                  −0.157483
合计：原模型平均校正           +1.031726
```

这里的“贡献”取决于声明的零路径参考状态，是固定计算图的分解，不是物理因果效应。

### 3.2 极端历史字段的作用

把 Newton 的 `pre_event_mean_osi` 标准化值从 153.437 设为 0，即设回训练均值，保持其他输入和权重：平均校正从 **+1.031726 变为 −0.176264**，总变化约 **−1.207989**。

再按这个字段进入 skip/message 的两种顺序分解，相对于“该字段设为训练均值”的状态：

- 经 skip 路径的平均贡献：**+1.220830**。
- 经消息路径的平均贡献：**−0.012840**。
- 两者合计：**+1.207989**。

该字段的 skip 权重向量 L2 范数约 **0.4976**，乘以 153.437 的标准化输入后，对应隐藏向量范数约 **76.352**。Newton 完整 skip 隐藏向量平均范数为 84.191，消息隐藏向量为 26.454。范数不能直接按百分比归因，但说明输入量级如何通过普通线性映射产生很大的隐藏表示。

同时做了范围敏感性检查：

| 固定权重下的输入操作 | Newton 平均校正 | 平均最终预测 |
|---|---:|---:|
| pre_event_mean_osi 限到监督训练范围最大值 | −0.131949 | 0 |
| 四个极端历史字段限到训练范围，并重算近邻摘要 | −0.029657 | 0.000516 |
| 所有节点、所有标准化输入统一限到 ±5 | −0.012842 | 0.002111 |

四字段为 `pre_event_mean_osi`、`osi_mean_72h`、`outage_pct_mean_72h`、`pre_event_max_outage_pct`。范围由该检查点的监督训练掩码计算；±5 仅为诊断探针，没有搜索阈值。

这些操作消除了此次巨大正偏移，却有的把 Newton 全部有效预测压为零，说明**“去掉放大”与“准确预测”不是一回事**。它们还是仅推理时的分布改变，不能直接用作部署修复。逐行值及明确标记为 diagnostic_only 的该县 RMSE 保存在 `tables/Newton_interventions.csv` 和 `Newton_intervention_timeline.csv`。

## 4. 检查点还说明了什么

- Newton 的 `residual_scale=0.012568478530908384`，与重建值吻合。原始校正约是这个尺度的 82 倍；不是漏乘尺度或 log/expm1 逆变换错误。运行名中的 `_log` 不改变其实际使用 MSE 标准化残差的事实。
- Newton 模型共训练 220 epoch，best_epoch=219，保存 best_loss≈0.086567685。该值是 **eval 模式下的训练监督 MSE**，不是独立验证误差。
- 全部 64 个检查点都运行到 220 epoch 上限；best_epoch 为 211–220，中位数 218，其中 20 个在第 220 epoch 最优。保存状态与 best_loss 数值一致，但“训练损失还在下降”不能证明对域外县的外推可靠。
- 缺少完整逐 epoch 权重/日志，不能确定 Newton 的异常从哪个 epoch 开始，也不能把不同 scope 的差异单独归因于随机 seed。

## 5. 对下一轮实验的含义

本次缩小了需要优先解决的问题：**应先让神经残差模型对训练支持范围外的输入保持稳定，再判断消息传播能否带来额外收益。** 单纯加深图网络或去掉 Newton，都没有依据。

建议新实验仍以当前主线 F2 为基准，并先冻结如下对照与选择规则：

1. 在各自允许训练 scope 内拟合统一的稳健输入变换/范围处理，训练和推理使用同一规则；如选择阈值，只能用内层。避免按县名关闭模型。
2. 对照树基线、使用同一信息的无消息传播残差网络、GAT。二者保持特征、残差目标、scope 隔离和 alpha 选择规则一致，才能分辨神经预测能力与消息传播增量。若要单独研究近邻摘要，还需另设信息对照。
3. 将校正幅度与范围外输入诊断列入每折输出；可考虑有界校正或域外回退，但须在内层选定规则，检查真正高损失县是否因此失去必要的大校正。
4. 在训练县内部决定 epoch/稳定性规则，并评估不同 scope 的迁移；继续保留严格外折隔离。最终以短时及全部 horizon 的整体 RMSE、最差县损失变化共同判断，不能以 Newton 事后分数选模型。

旧 GAT 的基线是旧同 horizon 分量重组，并非当前 F2，因此本次没有给出“GAT 相对 F2”的优劣结论，也没有启动任何新训练。
