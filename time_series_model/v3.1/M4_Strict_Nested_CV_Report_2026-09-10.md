# v3.1 M4 严格嵌套交叉验证报告

日期：2026-09-10  
状态：里程碑 M4 已完成  
评估级别：`strict_nested_cv`

## 1. 结论

v3.1 的 GRU 残差主模型没有通过预先规定的晋级条件。严格外层 OOF 中，B3 在 t+1h 基本持平、t+6h 被 alpha 安全门完全退回基线，在 t+24h 和 t+48h 的 RMSE 分别退化 2.23% 和 5.44%。因此不应把当前 GRU 用于 M5 最终模型，也没有依据继续做多随机种子或扩大网络。

本轮真正稳定的收益来自不训练新模型的 B1“目标时刻对齐平均”：t+1h、t+6h、t+24h 的 RMSE 分别改善 0.97%、2.13%、1.54%，MAE 分别改善 2.47%、4.87%、3.21%。t+48h 的 RMSE 退化 0.94%，因此若以 RMSE 为主要参考，后续候选应只在前三个 horizon 使用 B1，t+48h 保留 LightGBM。官方最终计分公式尚未发布，这个按 horizon 的选择应视为 M5 候选配置，而不是已经获得无偏评估的最终系统分数。

三个新增对照给出了明确诊断：

1. 常数残差校正几乎等于基线，说明 M3 的现象不能靠一个全局偏置形成稳定 RMSE 收益；
2. 未来气象对 t+24h 的 GRU 确有增量，但完整 GRU 仍未超过 LightGBM；
3. 普通 MSE 大多被 alpha 门控回基线，高 OSI 加权 MSE 则在四个 horizon 全部退化。

## 2. 严格嵌套协议

外层继续使用 `balanced_v1` 的五组县，每个县完整轨迹只能属于一个外层验证折。对每个外层折执行：

1. 只在其余四折县中进行 LightGBM 四折早停；
2. 每个 horizon 取四个最佳树数的中位数作为固定轮数；
3. 用固定轮数重新做 outer-train 内四折交叉拟合，产生合法残差标签；
4. 神经网络只在 outer-train 内选择 epoch 和 `alpha∈{0,0.25,0.5,0.75,1}`；
5. 在全部 outer-train 县上重训 LightGBM 和残差模型；
6. 外层验证县标签只用于最后评分。

训练损失先在每个 county/horizon 内对有效时间位置求均值，再在 county/horizon 间平均，避免长有效区间获得额外权重。神经网络最大 50 epoch、patience 10；加权 MSE 在第 1 外层折选到 epoch 50，其他模型和折均在上限前停止。总运行时间约 1,383 秒。

M4 没有生成测试提交。测试集最终训练与提交属于 M5。

## 3. 同折模型定义

| 编号 | 模型 | 诊断目的 |
|---|---|---|
| B0 | 严格嵌套 v1.5.6 LightGBM | 基线 |
| B1 | 目标时刻对齐平均 | 对同一县、同一真实目标小时的多 horizon 原始预测取平均 |
| B2 | MLP + Huber 残差 | 检查二级校准能否解释 GRU 收益 |
| B3 | 完整 GRU + Huber 残差 | v3.1 主模型，读取观测序列和未来气象 |
| B4 | 常数均值残差 | 检查模型是否只学习全局偏置 |
| B5 | GRU + Huber，不读未来气象 | 未来气象消融 |
| B6 | 完整 GRU + MSE | RMSE 对齐损失 |
| B7 | 完整 GRU + 高 OSI 加权 MSE | 强调稀有高停电样本 |

B5 保持与 B3 相同的结构和初始化种子，仅把未来气象张量置零；它仍读取前 72 小时停电和同期气象。这使 B3 与 B5 的差异可解释为未来气象的增量。

B7 的权重为 `1 + 4 × clip(target_OSI / 0.05, 0, 1)`，即正常样本权重为 1，OSI 达到 0.05 后最高为 5。

## 5. 配对不确定性

使用 2,000 次按县整条轨迹重采样的 paired bootstrap。差值定义为“模型减参考”，负数表示模型更好。

### 5.1 B1 相对 B0

| Horizon | RMSE 差值 | 95% 区间 | 改善概率 |
|---|---:|---:|---:|
| t+1h | -0.000116 | [-0.000288, +0.000026] | 94.45% |
| t+6h | -0.000229 | **[-0.000362, -0.000083]** | 99.95% |
| t+24h | -0.000133 | [-0.000323, +0.000025] | 94.60% |
| t+48h | +0.000072 | [-0.000216, +0.000309] | 33.00% |

t+6h 的区间完全低于零，是本轮最可靠的 RMSE 改善。t+1h 和 t+24h 方向较稳定但区间仍轻微跨零。B1 的 RMSE 改善折数为 5/5、5/5、4/5、4/5；t+48h 虽有四折改善，但少数高误差县使池化 RMSE 变差。

### 5.2 B3 相对 B0

| Horizon | RMSE 差值 | 95% 区间 | 改善概率 |
|---|---:|---:|---:|
| t+1h | +0.000003 | [-0.000010, +0.000013] | 36.85% |
| t+6h | 0 | [0, 0] | 0%（所有折 alpha=0） |
| t+24h | +0.000192 | [-0.000093, +0.000488] | 13.20% |
| t+48h | +0.000420 | [-0.000060, +0.000878] | 11.90% |

B3 的 RMSE 改善折数为 0/5、0/5、0/5、1/5，不满足“多数折方向一致”的条件。

### 5.3 时序、未来气象和损失函数

- B3 相对 B2 在 t+24h 的 RMSE 差为 -0.000306，95% 区间 `[-0.000567,-0.000035]`；t+48h 为 -0.000353，区间 `[-0.000650,-0.000006]`。时序顺序在中长跨度确实优于非时序 MLP，但两者都没有超过 B0。
- B3 相对 B5 在 t+24h 的 RMSE 差为 -0.000195，95% 区间 `[-0.000371,-0.000019]`，改善概率 99.05%。这是未来气象存在增量信息的证据。t+1h、t+6h、t+48h 的区间均跨零。
- B6 相对 B3 在 t+24h/t+48h 的 RMSE 点估计更好，但区间跨零；其主要原因是 MSE 模型被 alpha 门控回 B0，而非学到了新的稳定修正。
- B7 相对 B6 的四个 MAE 全部显著变差。固定的高 OSI 权重没有解决尾部问题，反而破坏普通样本校准。

完整比较见 `paired_bootstrap.csv` 和 `paired_bootstrap_extended.csv`。

## 6. 误差结构

### 6.1 目标时刻一致性

同一 `(county,target_hour)` 下多 horizon 后处理预测的平均标准差：

| 模型 | 平均标准差 |
|---|---:|
| B0 | 0.0009175 |
| B1 | 0 |
| B2 | 0.0009379 |
| B3 | 0.0009164 |
| B5 | 0.0009111 |

B1 按定义消除了不一致。B3 相对 B0 的变化很小，说明四个残差头没有自行学到明显的一致性约束。

### 6.2 时间相关和极端县

B0 的误差一小时自相关为 0.894～0.928；B3 没有降低这一水平，t+24h/t+48h 反而升至约 0.901/0.905。当前 GRU 未能消除主要的连续时段系统误差。

B0 最大误差县对总平方误差的贡献为 15.2%～26.5%。B1 在 t+48h 把最大县贡献从 22.7% 提高到 24.6%，解释了“多数折改善、池化 RMSE 仍恶化”的现象。B3 在 t+48h 也提高到 25.4%，其退化同样受极端县影响，但并非可以删除这些县解决的问题。

### 6.3 风暴阶段

B1 的 t+6h 在四个风暴阶段 RMSE 全部改善约 1.57%～2.65%，表现最稳定。B3 在 t+24h 第二波阶段退化约 3.84%，t+48h 第二波阶段退化约 6.24%；长跨度的总体问题主要发生在高影响的第二波，而不是消退阶段。

## 7. v3.1 通过条件复核

| 条件 | 结果 |
|---|---|
| B3 严格 OOF 优于 B0 | 未通过 |
| 多数外层折方向一致 | 未通过 |
| 收益不依赖少数极端县 | 没有形成收益；长跨度退化受极端县放大 |
| B3 优于 B2或改善一致性 | 只在 24/48h 优于 B2，但未超过 B0；一致性几乎不变 |
| 没有不可接受的 horizon 退化 | 未通过，24/48h RMSE +2.23%/+5.44% |
| 模型重载逐值一致 | 通过 |

综合判断：**v3.1 GRU 路线在当前结构、样本规模和目标定义下不进入多 seed 或更复杂模型阶段。** 未来气象不是没有信息；问题是当前残差 GRU 无法把这部分信息转化为相对强 LightGBM 的稳定净收益。

## 9. M5 建议

M5 不应训练或提交当前 B3 GRU。建议把候选范围收窄为：

1. B0：完整保留 v1.5.6 LightGBM；
2. B1：至少对 t+6h 使用目标时刻对齐平均；
3. 候选混合：t+1h/t+6h/t+24h 使用 B1，t+48h 使用 B0。

由于官方评分公式未知，M5 冻结前应明确是优先 RMSE、MAE，还是四个 horizon 的某种加权组合。若继续研究未来气象，优先考虑直接预测统一未来 OSI 轨迹或给 LightGBM 构造目标时刻一致的紧凑天气特征，不建议先扩大当前 GRU。
