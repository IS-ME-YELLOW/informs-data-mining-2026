## 3. M2 模型契约

实现的正式模型接口为：

```text
candidate logits -> masked softmax -> dynamic weights
final weights = (1-alpha)*equal weights + alpha*dynamic weights
prediction = sum(final weights * raw LightGBM candidates)
```

训练损失是在唯一目标轴上与四 horizon 等权 MSE 等价的加权 MSE。GRU 不预测自由残差，最终预测始终位于可用 LightGBM 候选的凸包内。
