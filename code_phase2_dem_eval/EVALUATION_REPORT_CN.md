# Phase 2-E 官方评估规则下的模型报告

## 1. 评估依据

本报告使用比赛附件 `evaluation_procedure.pdf` 的官方规则：

- 每个预测时距分别计算 pooled RMSE；
- 四个 horizon 的名次取平均，作为总排名；
- 平均名次相同时，用 t+1h RMSE 决胜；
- MAE 不参与官方排名，但本报告仍保留 MAE 和其他统计量作为诊断指标。

官方测试集应包含 63 个县，提交文件中的有效行数应为：

| Horizon | 官方可评分行数 |
|---|---:|
| t+1h | 9,009 |
| t+6h | 8,694 |
| t+24h | 7,560 |
| t+48h | 6,048 |

当前 CV 指标是训练县 OOF 结果，不是官方隐藏测试集成绩。`submission_audit.csv` 对提交模板进行结构检查。

## 2. 运行配置

- base model：`component_v21`；
- GAT loss：`mse`，与官方 RMSE 目标一致；
- GAT 输入特征：257 维；
- 县节点：302 个，其中训练县 239 个、测试县 63 个；
- 图边：3,028 条；
- 图：8-NN + county border + edge features；
- epochs：220；
- folds：5；
- time stride：1，使用完整 144 个预测时间片；
- 设备：CUDA；
- 预测变量仍遵守因果规则：outage 输入只使用观测窗口，天气使用题目允许的预报字段。

## 4. 相对于 LightGBM 的变化

“改善”表示误差下降；R² delta 表示 DEM-GAT 减去 LightGBM。

| Horizon | RMSE 变化 | MAE 变化 | MedAE 变化 | R² delta | 官方判断 |
|---|---:|---:|---:|---:|---|
| t+1h | 0.000% | 0.000% | 0.000% | 0.000000 | 持平，GAT alpha=0 |
| t+6h | -0.323% | +1.370% | +0.952% | +0.001965 | 官方指标改善，但平均绝对误差略差 |
| t+24h | -1.254% | -1.477% | -8.662% | +0.013045 | 明显改善 |
| t+48h | -1.545% | -0.843% | -6.963% | +0.019336 | 最明显改善 |

当前模型在四个 horizon 中取得：

- 官方 RMSE：3 个 horizon 优于 LightGBM，1 个 horizon 持平；
- MAE：2 个 horizon 改善，1 个 horizon 恶化，1 个 horizon 持平；
- R²：t+6h、t+24h、t+48h 均提高。

平均来看，DEM-GAT 的 RMSE 约为 0.009596，与 LightGBM 的约 0.009661 相比下降约 0.68%。该平均值仅用于辅助观察，官方总排名不是四个 RMSE 的简单平均，而是四个 horizon 的平均名次。

## 5. 官方 alpha 选择结果

alpha 现在只根据 pooled RMSE 选择，MAE 不再影响提交模型的融合权重：

| Horizon | Selected alpha | Pooled RMSE |
|---|---:|---:|
| t+1h | 0.00 | 0.0119576848 |
| t+6h | 0.05 | 0.0105624360 |
| t+24h | 0.20 | 0.0083446661 |
| t+48h | 0.20 | 0.0075227626 |

这说明空间残差对短时距 t+1h 几乎没有可泛化贡献，而对 t+24h 和 t+48h 的帮助更稳定。

## 7. 结论

按官方评分规则，当前 `code_phase2_dem_eval` 比原来的 `RMSE + MAE` alpha 选择方式更正确，因为训练和融合目标已经对齐官方 RMSE。正式 OOF 结果表明，该版本可以作为当前候选提交模型：t+24h 和 t+48h 的提升最有价值，t+6h 有小幅 RMSE 提升，t+1h 自动退回 LightGBM。

但这些仍是训练县 OOF 结果，不能等同于隐藏测试集排名。由于 t+6h 的 MAE 上升，以及 DEM-GAT 收益主要集中在长 horizon，下一步应重点做：

1. 对四个 horizon 分别做 county-level paired bootstrap，确认 RMSE 改善是否稳定；
2. 增加 tail RMSE 和 high-OSI recall，检查官方 RMSE 改善是否来自合理的极端事件修正；
3. 将静态图升级为天气条件动态边图；
4. 保持完整 144 个时间片，加入 GRU/TCN 时间编码；
5. 用隐藏测试集提交结果决定最终是否保留 DEM-GAT，而不是仅依据 OOF 结果增加更多静态 DEM 特征。
